Aplikasi Ujian

Klien resmi untuk ujian di Windows dan Android
Windows 10 / 11

Aplikasi Ujian Windows

  • Fullscreen kiosk, tanpa menu dan DevTools
  • Blokir Alt+Tab, Alt+F4, dan pintasan lain
  • Proteksi screen capture pada jendela ujian
  • Deteksi proses mencurigakan dan multi-monitor
Unduh Installer (.exe) Unduh Versi Portable
Jalankan sebagai administrator saat memasang
Android 7.0+

Aplikasi Ujian Android

  • Blokir screenshot dan rekaman layar aplikasi
  • Layar penuh dan tombol kembali dikunci
  • Screen pinning saat ujian dimulai
  • Deteksi root, emulator, dan multi-window
Unduh APK
Izinkan pemasangan dari sumber tidak dikenal (sideload)

Cara memakai

  1. Pasang aplikasi di perangkat yang akan dipakai ujian.
  2. Buka aplikasi, lalu masuk memakai NIS dan sandi seperti biasa.
  3. Pilih ujian, lalu tekan Mulai Ujian.
  4. Jangan menutup aplikasi sampai ujian selesai dikirim.
Penting: aplikasi ini menaikkan keamanan, tetapi tidak bisa menjamin kunci mutlak di perangkat pribadi (BYOD). Siswa yang memegang hak admin tetap bisa mengakali perangkat. Pengawasan guru, soal yang variatif, dan pengamanan server tetap wajib.
Jika tombol unduh belum tersedia, hubungi admin sekolah. Berkas diletakkan di folder downloads/ pada server.
